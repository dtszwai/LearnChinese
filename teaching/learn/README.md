# 學習單元的出題依據

此目錄供內容維護及覆核使用，位於 Docusaurus 的 `docs/`、`static/` 和前端匯入範圍之外，不會顯示於學生頁面。

## 檔案

- `sources.json`：已查閱的教育局及香港大學教學資源，包含網址、章節位置與適用範圍。
- `review.json`：新增五課每一步的來源 ID、出題／答案理由及可接受答案。以 `stepId` 對應 `src/data/Learn/*.json` 的 `id`，不依賴容易變動的頁碼。
- 學生頁面只匯入 `src/data/Learn/` 的課程資料；上述來源及備課記錄不會被匯入。

## 編寫與覆核原則

對象為香港中學生，從初中基礎開始，逐步銜接閱讀分析。年級安排參考課程與校本教學示例，不宣稱全港統一進度或考試頻率。

每課包含概念介紹、已填答案的示範、即時練習、情況變化、易混淆例子及綜合應用。按內容使用點選選項、原文詞語點選、事件排序或短答；較開放的作用分析使用有具體語境的選項，避免用字稍異便被判錯。選擇題把選項與提示合併在單一容器，以選項狀態表示對錯；原文詞語點選及排序題答對後顯示簡短解說，排序可撤回和重排。

所有預填示範均可編輯；預填只提供起點，不繞過答案判定。改錯或清空後，「下一題」必須重新鎖定，改正才解鎖。各題型共用原有的「顯示答案」提示及 ALT + H 快捷鍵；查看答案不會自動作答或解鎖下一步。

答案判定使用 OpenCC（opencc-js）把繁簡文字轉為同一形式再比對，並容許首尾空白。學生的輸入保留原字形；摘錄題以相應的原答案標示原文。此相容處理不代表接受未列出的同義答案，也不把學生輸入當作任意可通關的正則式。新增答案時須同時核對繁簡轉換後有否產生語義混淆。

現代文例句、題目及解說為自編。古典短句採用公版原典，按教育局篇章資料核對文字與解釋，並在學生題目標示篇名。沒有轉載出版社課本或其整套練習。論證題中的虛構事例明示「自擬情境」，不得當作真實調查數據。

重要辨析：

- 描寫：分清描寫內容（動作、心理等）與描寫途徑（直接、間接）；能推測心情的動作，不必然就是心理描寫。側面描寫題須指定主要對象。
- 抒情：景物或物件的出現不足以證明抒情；需有語境及文字證據。允許同一段兼用多種方式，題幹限定分析範圍。
- 記敘：以敘述主線及全文／段落次序判斷；不能僅憑過去時間詞判倒敘。伏筆、鋪墊、照應的作用可以重疊，不設僵硬互斥的判斷題。
- 論證：區分論點、材料和推論；「有引號」不等於引用論證，「有例子」不必然就是舉例論證。單一例子不能推出人人必然如此。
- 文言：字義、代詞及省略成分依所列原文語境判斷；課程只介紹部分常見用法，不把一個翻譯當作該字的全部意思。

## 覆核狀態與維護

2026-10-20：完成來源核對與編寫者逐題覆核；尚未經獨立中文科教師審定。教育局及大學來源支持教學概念，並不表示它們審核或認可本站自編題目。

修改題目時同步更新 `review.json` 的理由和答案。更換原典例句時須重新核對原文、注釋、指代及省略，不沿用舊句的解釋。新增別名應確認與題幹的填空語法相容。

執行 `yarn check:learn` 檢查來源對應、示範初值、所有可接受答案、摘錄匹配及完成頁。它能檢查資料和程式相容性，不能代替語文內容覆核。最後執行 `yarn build` 並在瀏覽器檢查作答、提示、前後導航及進度恢復。
